# 响应合同内部异常排查与任务批量软删除

## 问题与范围

公司环境报告资源列表与小时归档列表发生 `ResponseValidationError`。旧访问日志仅含异常类型与框架栈，缺少字段位置，无法据此认定现场唯一触发字段。本轮按资源/Core/监控、日志/下载/检索、任务/命令/身份、节点/管理/事件四组审查生产写入、公开投影、历史可选字段及状态分支，保留运行时严格响应合同，禁止以放宽未知字段或按合同静默吞字段来掩盖实现遗漏。

## 已确认的问题与修复

| 入口或领域 | 证据及处理 |
| --- | --- |
| 资源列表/详情 | 健康检查租约、健康恢复领取计数、监控续租时间与从机端口有真实持久化写入路径，但属于内部协调状态。公开投影明确剔除 `healthLeaseUntil`、`healthLeaseStartedAt`、`healthLeaseToken`、`healthConsumeClaim`、`resourceMonitorCheckedAt`、`slaveSshPort`；正式资源列表回归检查200及字段不泄露。 |
| 小时归档与下载冻结文件 | 文件 `deploymentRecovery` 含内部恢复令牌和节点路径；在日志文件专用公开投影移除，保持任务既有同名字段合同兼容。小时归档、创建下载及旧作业快照正式路由覆盖。 |
| 下载作业查询 | 内核锁恢复写入 `outputWriterClosureReason`，该内部原因不属于公开作业合同；明确剔除并验证已完成作业查询。 |
| Core/监控/搜索/索引/下载历史 | 核对专用投影与生产发布字段，没有将未知历史数据猜测为正常业务字段；保留原始合同及其严格校验。 |
| 任务/命令/模板/用户/服务令牌 | 审查实际写入、历史缺省和nullable；保留既有公开任务部署恢复字段，未额外扩大接口兼容性变更。 |
| 节点/平台配置/事件 | 核对节点心跳、维护、关闭、领取和隔离写入；补首次采样、过期、隔离、关闭四态正式HTTP回归，事件保持统一展示器安全投影。 |

## 请求编号排障

500提示明确指向“审计与事件 → 请求记录”，按请求编号和包含故障时刻的时间范围查询；API为 `GET /api/v1/request-events?requestId=...`。运行事件不是全部HTTP请求的记录入口。

新 `responseValidation` 由响应合同自动进入API字段释义；最多20项错误、每项12层路径。只显示对应合同分支的静态字段、数组下标和标准错误码；未知字段、动态字典键和无法确定的联合分支隐藏。不记录Pydantic原始 `input`、`ctx`、`msg`。诊断辅助失败降级为null，不能阻止原始500请求事件落库。

请求事件原有0.2秒持久化超时、30天保留和数据库故障边界保持。旧日志缺失的字段信息无法事后恢复；可按requestId查询API标准输出和服务JSONL。详见 `docs/operations.md`。

## 批量软删除

任务页复用现有逐任务DELETE接口，按当前页选择串行提交，冻结确认的ID与版本；取消不发请求，选择/筛选失配停止旧请求，单项冲突不阻断其余任务。权限、所有权、已删除状态保持既有校验。结果逐项显示，成功后刷新隐藏；任务日志及已有下载文件仍按原保留期处理，不因删除任务直接移除。
