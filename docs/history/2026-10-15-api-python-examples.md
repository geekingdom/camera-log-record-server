# API文档核对与Python调用示例

## 需求与设计

以本次实际注册的公共HTTP路由及WebSocket为准核对站内目录、权限、参数和说明。继续由OpenAPI生成目录，针对协议特殊行为补充明确规则，不另维护一份手工接口清单。每个操作增加pythonExample，展示完整Python源码及依赖说明，支持复制但不在文档页面执行。

普通接口使用requests和Bearer服务账号；登录会话限定接口通过Session完成登录并复用Cookie；二进制下载流式写入，文本指标按文本处理，204不解析JSON；WebSocket首帧认证、持续接收日志。示例仅使用虚拟ID及地址，真实口令和令牌由环境变量提供。说明幂等键复用、当前版本号与异步作业状态边界。

## 验证计划

路由集合与目录集合精确一致，逐接口Python语法检查及替身执行检查，关键请求输入模型/参数校验；浏览器检查每接口展示、Python复制、无副作用和桌面/移动布局；全量Python/Ruff/前端测试构建，真实隔离浏览器冒烟；中文提交后等待最新GitHub所有检查成功。

## 实现与本机验证

目录版本1.1，89个操作（88 HTTP、1 WebSocket）全部提供独立Python源码。请求示例仍来自实际路由Schema，嵌套正文缩进、依赖与环境变量说明一并复制。会话与响应在finally回收，下载先写partial再重命名；幂等键必须显式配置，不使用固定回退键。页面只展示和复制，不执行代码。

核对更新了资源看板权限与统计口径、认证全部同结果周期记录合并、401拒绝锁存由周期或人工SUCCESS解除、SSH主从协议与保活、CPU/内存/Coredump负责人范围及检索取消权限。逐接口执行发现log-days的month示例原为example，已按YYYY-MM契约修正。

本机全量1903项通过、1项月份示例失败后，修复并复跑API专项27项全部通过；前端195项、生产构建、全仓Ruff通过。89段源码语法检查、88个HTTP替身请求体/查询校验、WS首帧与数据处理均通过。1440/390/320浏览器复制、错误重试及无横向溢出通过；真实隔离Worker/WebSocket/小时下载冒烟通过，无控制台异常，临时数据库及日志已清理。替身执行不代表对公司真实环境执行过全部写接口。
