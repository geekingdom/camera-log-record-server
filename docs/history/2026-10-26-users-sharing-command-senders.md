# 用户重建、资源共享与删除处置验收

## 范围与行为

- 软删除账号可按新配置重新创建同名用户，新ID与旧会话、令牌及共享关系隔离；活动用户名仍唯一。
- 删除用户必须为其活动资源选择同步软删除或转移；前端不预选删除。转移目标为任意启用且未删除的其他平台用户，不要求资源或任务写权限。其后实际操作仍受个人平台权限限制。
- 资源显式指定共享用户，默认空名单；共享扩展编辑、认证、关联任务控制和命令资格，不授予资源删除资格，也不提升平台scope。任务共享沿主设备资源，串口服务器共享不扩散到其他设备。
- 资源转移及原用户创建的关联任务归属、用户删除和逐项审计同事务提交；其他用户任务不变。软删除保留历史日志，仍按既有保留期处理。
- API文档导航仅对持有未撤销、未到期服务账号的当前用户显示，管理员同规则；登录、身份刷新及改密时计算资格。该需求调整导航入口，不新增文档接口鉴权限制。
- 手工命令记录提交时用户名快照；定时命令显示系统，缺快照历史记录明确未知，不以重新注册的同名账号冒认。

## 合同与文档

共享名单、当前用户文档资格、命令发送用户名与处置审计上下文声明在实际请求/响应合同。删除用户的Query参数明确DELETE/TRANSFER及接收目标。站内文档从运行时合同生成，README、用户权限、设备资源和数据库保留文档同步。
