# 工作区导航与窄屏资源布局验证

起点提交 `b5c6ffb`。用户明确继续完整目标；本轮接续工作区中尚未提交的前端导航抽取，实现模块化和响应式稳定性，不重复数据库或SSH已交付功能。

## 实现

- `frontend/src/app/useWorkspaceNavigation.ts` 集中Hash同步、权限回退、资源任务跳转和刷新调度；同步修改页签、页码与资源筛选只刷新最终快照一次。
- 请求繁忙、认证尚未完成、强制改密期间保留刷新意图；未登录时不按匿名导航回退到API文档。组件卸载后排队刷新失效，同步异常进入错误入口。
- App刷新finally检查会话代次，旧请求不得清空新登录的busy。轮询和用户操作共用在途锁；普通刷新优先于待执行静默意图。任务响应检查请求筛选快照。App为499行，组合模块129行，避免通过压缩排版降低行数。
- `ResourceWorkspace.vue` 在767px及以下取消固定操作列，桌面保留固定；注册的matchMedia监听在卸载时释放。
- 隔离冒烟脚本改用PyMongo URI解析及全部seed回环判断，兼容带凭据与IPv6本机URI，拒绝远程/混合/SRV/无效地址。

## 验证

- 前端20个测试文件、107项通过，类型检查及Vite构建通过。导航12项覆盖同页资源过滤重置、第2页归位、权限、Hash、会话、busy、同步异常、慢轮询合并及卸载；集合测试增加旧筛选响应在下一请求发出前不得回写。
- `browser_default_resource_navigation.mjs` 首次复现初始Hash空值回归，修复后通过。跨页进入任务列表和同页重置各1次请求；刷新保留任务页；资源第2页刷新保留页码；退出重登资源页；无权限回退资源页；无控制台异常。
- 独立审核指出静默轮询绕过调度，浏览器阻塞一次响应超过5秒后复现请求数6而非5。统一在途锁后，同一回归确认无并发、切页等待及结束后仅一次最终刷新。脚本需等待补发请求的response再统计，单独networkidle或request事件不证明模拟路由已处理完成；该观察竞态已修正。
- `browser_workspace_layout.mjs` 验证1440/390/320下任务选择筛选、状态更新、工作台视图切换和资源快捷创建。桌面主体x=216、宽1224；手机x=0、宽分别390/320，视图切换均不变化。
- 目视导航截图发现390宽固定操作列遮挡资源身份，修复后确认名称可见，表格仍能内部横向滚动；浏览器断言窄屏不存在fixed-right列且横向滚动范围大于0。桌面/手机截图位于output/playwright/navigation-*.png，任务选择截图task-picker-*.png。
- 本机隔离`verify_isolated_browser_smoke.py`调用正式`browser_smoke.mjs`通过：真实API、Worker、本地合成Telnet流、WebSocket、命令模板、任务、小时下载及浏览器操作。unexpectedConsoleErrors=0；首次未登录401为预期。
- URI校验新增10项测试及Ruff通过，拒绝远程或混合目标。隔离脚本只检查配置seed为本机，不为外部Mongo拓扑提供隔离证明。
