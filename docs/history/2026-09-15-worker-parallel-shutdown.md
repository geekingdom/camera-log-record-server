# Worker已有收尾不阻塞其他连接关闭

## 复现与约束

原`Worker.close`首先等待所有`releases`，然后才关闭剩余`active`。只要一路已开始的收尾仍在等待，其他设备连接就不能开始关闭。新增闸门测试先复现：保持已有release未结束时，另一任务的stop在观察窗口内始终未被调用。

修复同时启动已有收尾的等待与剩余会话关闭。已有release对应的任务ID从新关闭列表中排除，不能重复stop，不能为提前退出而取消磁盘写入或释放未知归属。剩余会话仍使用既有16路并发批次，不增加SSH连接。

## 边界

永久阻塞的落盘仍可能超过Docker的120秒宽限期，不能宣称此时可完整退出或自动安全接管。修复保证已开始的收尾不会延迟无关会话收到关闭请求；未知关闭仍须保留锁并隔离。物理多节点故障和长期背压验收未完成。
