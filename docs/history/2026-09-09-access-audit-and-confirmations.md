# 来源访问、认证审计与命令确认

日期：2026-09-09。基线：`44f6514`。当前需求与剩余工作以 [总表](../implementation-status.md) 为准。

## 边界与变更

- IP 白名单只匹配 ASGI 请求的客户端来源。设备资源认证和 SSH/Telnet/串口目标不参与匹配。集成测试使用白名单外设备创建资源及任务，并请求启动串口任务；网络为模拟，不声称连接实体设备。
- 请求日志中间件移至来源策略外层，使提前拒绝的 403 也有一致的响应头、错误体和日志 requestId。记录 clientIp，不记录请求 query、header、body。
- 登录成功、退出已有会话后关联操作者；新增密码、散列、密钥与 Cookie 字段脱敏。
- 设备认证预览写入精简业务审计，只保留操作者、动作、目标和时间，不保留凭据与设备响应正文。既有设备身份变化返回 409 并单独记录身份变化，不误报成功；串口预览不产生虚假的网络认证事件。
- 初始化及定时命令草稿删除增加二次确认。确认后按对象重新定位，取消、列表重排、同文命令及模板替换不会删除错误对象。

## 未完成边界

资源、模板、用户等部分业务变更与审计写入尚非同一事务；变更成功后审计失败仍可能出现业务事件缺失。HTTP 访问日志不等于 Mongo 业务审计，限流/CSRF 等拒绝未逐一写业务事件。本轮不扩大为所有变更的事务改造。

没有重启真实采集 worker，没有向真实设备发送命令，没有新增合成采集日志或删除真实设备日志。500 路全天容量、实时缺口补读及服务端合成数据清理器仍按总表推进。
