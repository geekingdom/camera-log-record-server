# 实时省略范围与按字节补读

基线 `60bcf77`。本轮处理总表 R17，不更改设备连接、命令或归档协议。开发前执行 CodeGraph sync 和 LiveLogBuffer 影响分析；图谱仅辅助定位，结论通过源码、测试和浏览器核对。

## 最终实现

- `frontend/src/shared/composables/liveLogBuffer.ts`：在解码前按会话、文件和字节偏移去重。限速省略、保留行淘汰、已知传输跳跃及被切断的半行保留原始半开范围 `[start, end)`，包括换行字节。相邻同来源范围合并但不跨越已展示正文，保留稳定 ID 并刷新最近更新顺序。
- 缓冲保留 5000 行、200 个缺失范围和 200 个文件水位。丢弃的范围计数独立于省略行数；长行按不超过 65536 字节的显示片段切分并保护 UTF-8 边界。已展示行仅保留文本和合并后的来源元数据，不引用整帧后备字节。原始磁盘正文不受影响。
- `frontend/src/features/logs/LiveLogRanges.vue`：点击“查看省略范围”，选择记录后按固定终点读取，单次最多 65536 字节。仍使用正式内容 API 的权限和读取限流。检查响应文件、会话、字节数和 nextOffset；失败与空页不推进游标，可以重试；取消、任务切换和卸载中止请求并拒收过期响应。请求有 30 秒超时。
- 实时窗口继续独立接收，暂停本地视图也继续记范围。补读内容显示于独立窗口，不插入实时流，不把历史补读标成新的设备输出。预览最多保留最近 262144 个字符，发生截断明确显示；原文件可从小时归档下载。

服务端 gap 事件当前只有消息，没有精确文件边界时不虚构范围，提供小时归档入口。跨文件半行的来源分别记录、分别补读，独立范围起止于 UTF-8 字符中间时显示可能有替换字符；实时连续流仍保留跨文件字符拼接。用户清空或切换任务会清空本地范围，持久化日志不删除。

- `scripts/browser_live_ranges.mjs` 使用模拟 API/WS 驱动真实页面：250 行一帧，展示上限 200 行；精确补读 `[1083600,1354500)` 共 270900 字节，分五页完成；暂停继续接收、传输跳跃、未知 gap 转历史、关闭后的迟到响应及任务切换隔离通过。桌面 1440 与移动 390/320 视口截图位于 `output/playwright/live-ranges-*.png`，已核对布局。

- 真实 API 窗口截图：`output/playwright/browser_r17_ef9dd773a78d4079bcc2eb34cad47169/live-range-real-api.png`，其中已定位 `[418000,456000)` 且读取至固定终点。模拟数据只证明这一条测试流，不代表 500 路全天容量达标。

全链路最初因一条控制台 401 未通过；加上错误 URL 后确认是全新浏览器登录前的 `/api/v1/auth/me` 探测。脚本仅把登录完成前、该精确 URL 的首次 401 单独计数，登录后及其它错误仍导致失败。最终 `initialSessionChecks=1`、`unexpectedConsoleErrors=0`，不把正常认证流程伪装成完全没有 HTTP 401。
