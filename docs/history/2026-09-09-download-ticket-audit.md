# 浏览器下载授权审计事务

原流程先插入下载票据、设置Cookie，最后记录审计，审计失败可能遗留未记录的有效票据。两项回归先在旧代码失败，再将固定票据摘要和审计放入共同事务。只有事务提交或多数主库确认本次票据存在后才设置Cookie，未知结果返回503；取消异常向上传播。没有改变已有下载路径、权限和五分钟有效期。

`scripts/verify_download_ticket_audit.py` 在随机独立MongoDB副本集测试库通过正式API验证审计失败和取消整体回滚、无Cookie发布，以及提交确认丢失只读恢复、票据与审计各一份。临时库和目录删除已确认；没有连接设备或更改实体任务。该脚本已加入容器CI。

本地后端全量743项、定向六项及Ruff通过，代码复核与diff检查通过；新提交Linux CI结果待收取。本机API/Worker未更新。此项只补齐授权审计；`logs/jobs.py` 的完成状态与审计仍需继续处理，文件产物与数据库提交不可能直接共享事务。
