# Collector命令派发模块化验证

日期：2026-09-11；起点：0529a18。按持续目标推进模块化，主代理编写独立行为回归、整合并验证，子代理负责提取实现及独立复核。修改前执行CodeGraph sync和Collector impact，最终以源码、行为回归和归档摘要为依据。

## 责任边界

Collector从541行降至445行；183行CommandDispatcher持有单会话优先队列、递增序号、发送future、提示符缓冲、PSH对话及发送前守卫。Collector保留初始化、定时编排、连接回收、单接收器和日志落盘/归档。初始化、手动、定时与NFS挂载/卸载继续使用同一队列，未新增设备连接。

提示符每次安装重新清空尾部；成功、超时、写入异常和取消统一清理等待器。单字节提示符保留0字节尾部，避免负零切片保留整段输入。排队命令在守卫、PSH恢复、预算回调后重检调用方取消状态，取消后不继续写socket；预算回调开始前取消不扣预算，开始后不承诺撤回已持久预留。
