# 已删除资源历史趋势与指标日期提示

## 行为

已删除海康资源可从设备资源列表打开 CPU 与内存趋势，即使原监控开关已关闭。预设范围为删除前 30 分钟/1 小时；不启动自动刷新或恢复采集，可手动刷新、查询更早历史和导出 CSV。数据仍按原资源指标保留期清理，不能恢复已过期样本。已删除资源或已删除任务的旧租约不显示为当前采样归属。

自定义日期选择器按上海日期在有指标采样的日期右上角显示绿色圆点，样式与小时归档一致。仅查询两侧面板及补齐日期所属月份，不读取整月趋势明细。空日期仍可选；加载失败明确提示，重新打开重试，快速翻月/关闭时忽略迟到响应。移动端上下排列两个日期面板并允许内部滚动。

新增月份查询接口的请求和响应中文释义来自实际运行时模型，自动进入站内 API 文档。保留期内异常采样也属于采样记录，圆点不代表每项指标都有有效值，也不代表有原始日志。
