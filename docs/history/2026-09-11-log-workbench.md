# 日志工作台验收记录

本轮从 `5ee6667` 开始，业务范围为日志工作台七项优化及专业连接软件风格。主代理负责布局、接口契约、整合审查和状态表；子代理分别负责实时终端、归档阅读器、后端完整行检索与独立复审。CodeGraph 用于检查共享搜索函数影响，最终以源码、回归和浏览器证据为准。

## 实现边界

- 工作台紧凑任务栏、工具栏与全高深色等宽日志区；侧栏折叠后动态扩展。提供字号、跟随、暂停视图、清空、查找及匹配导航。
- 日志级别着色和高亮使用安全 Vue 文本节点，不执行设备 HTML，不改变采集文件。实时查找针对最多5000行的本地视图，导航最多1000个匹配并明确显示上限。
- 成功提交的手动命令按用户及任务存入 sessionStorage，最多100条；支持上下键、保留输入草稿及下方候选。输入法组词和无发送权限都不能提交命令。
- 归档默认上海今天；单日选择同时决定历史检索范围。搜索结果按完整匹配行返回，一行多次出现关键词只返回一项，携带命中及行首原始字节位置。
- 完整行缓冲256KiB；命中超长行明确失败。在线程收集阶段限制1000项及8MiB正文，避免先收集过多结果。非UTF8预览返回encodingError标志；原始文件不受影响。
- 文件元数据按logs:read鉴权且只返回允许字段。上下文阅读每段最多256KiB，128字节重叠、UTF8边界处理、前后导航锚点及文件/会话/偏移验证；只保存当前段正文。
- 关键词时间范围统一为半开区间，结束时刻不纳入。缺时间索引的旧归档沿用关键词兼容检索，不能据此推断精确接收时间；空关键词查询仍拒绝无索引文件。

- 前端25个测试文件127项通过，最终生产构建通过。
- `browser_workspace_layout.mjs`：1440/390/320侧栏、任务选择与页签切换无横向漂移。
- `browser_live_terminal_workbench.mjs`：1440/390/320着色、安全文本、虚拟滚动查找、命令历史、输入法和权限、侧栏扩宽通过。脚本只发3次模拟正常命令；没有实际设备命令。
- `browser_live_ranges.mjs`：200行显示/50行省略，270900字节范围分5次精确补读，错误文件、会话、水位与超范围响应拒绝，暂停及迟到消息隔离通过。

## 过程纠正与未验收

- 旧实时范围脚本仍使用已删除的任务下拉框，已改为现有选择对话框。终端脚本的命令次数曾跨视口累计，修正为每轮基线；不是产品输入法误发。
- 独立审核发现关键词结束时间包含边界与时间查询不一致；2项先红、修复后77项相邻回归通过，最终全量1258项通过。
- 本轮未对34/35发送debug、kill或reboot。此前暂停重启验收任务保持STOPPED、没有run或文件；其资源已软删除，并重新查库核实。
- 交付保留`verify_ssh_paused_reboot.py`及定向测试作为既有验收准备。脚本必须显式指定单任务及reboot确认，尚未证明物理设备长重启流程通过。
- 500路全天、原口径文件可读P99、真实Linux多机及大文件故障矩阵依然未验收。
