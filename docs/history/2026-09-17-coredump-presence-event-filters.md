# Coredump提示与事件查询验收

## 最终行为

资源列表/详情返回hasCoredumps，列表支持true/false过滤，分页和总数均在存在性筛选后计算。红点表示存在，不表示未读，打开抽屉不会消除。Coredump附属coredump_flag.cdf不计入，源已明确缺失且无有效FROZEN副本的条目不计入。Worker每轮有界复核历史源，根目录/设备目录不可达及权限失败保留最后已知状态，不误判删除。查询不访问远程Worker文件系统。

每个目录文件版本以确定性事件ID登记COREDUMP_DISCOVERED，包含资源、文件、节点、首次观测时刻、发现时大小及版本。失败后下次观察补写，事件成功确认后不重放；按原receivedAt补历史，不把升级时间伪造成崩溃时间。运行事件沿用后台默认90天保留，不记录文件正文或宿主机绝对路径。

运行事件与审计记录的筛选名称均为事件摘要，可用中文显示名称查询；旧type/action精确参数继续支持。运行事件新增object，可按资源/任务/节点名称、IP、ID及持久文件名筛选；候选关联对象超过1000返回明确422，不静默截断。查询与时间、结果及游标组合，权限保持管理员限定。
