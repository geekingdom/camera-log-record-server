## 命令通道

源码核实首次 debug 恢复失败后，普通命令在入队或发送处被直接拒绝，普通定时项直接退出。即使设备随后恢复 shell，仍需额外 debug 才可恢复，违背失败仅影响当次的要求。

修改为所有后续命令均在唯一发送队列内重新确认 shell；不重发前次 debug 或口令。未确认 shell 的定时项等待完整间隔再尝试，不占预算、不结束调度。已实际发起的 debug 失败仍占用一次预算且不内部重试。原始日志接收持续。

明确设备侧边界：仍处于密码提示时不能把普通命令当作口令写入。当前初始化项跳过、手动命令失败；后续命令可以重探，定时项等待。不得宣称任意设备密码交互状态下都可以强制执行业务命令。

新建 `test_debug_recovery_retry.py` 的 4 项测试在旧实现失败，修复后通过；与现有 debug 采集、运行时、手动恢复共 27 项通过。`contracts.py` 独立连接协议、不可变日志块和回调合同，采集器降至 500 行内，保持既有导出可用。
