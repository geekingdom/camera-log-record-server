# 节点性能推荐验证

## 实现合同

新增需求是在节点已有资源识别之上给出可直接采纳的推荐，并保留管理员手动调整。`node/performance_recommendation.py`只读取新鲜心跳及资源遥测；`administration/settings.py`公开独立`performanceRecommendation`，不写数据库策略。已登记节点与未登记发现节点均可返回建议。未知资源、离线/过期遥测或不足64MiB可用内存时不伪造推荐值。

推荐基于有效CPU及可用内存，包含容器限制；不检测磁盘最佳IOPS，不把CPU/总内存换算为保证吞吐。规则及参数见`docs/node-performance.md`。后台编辑器展示依据、推荐值、刷新和应用入口，应用后允许手动调整，最终仍需保存确认；刷新只更新推荐，不覆盖草稿或配置版本。
