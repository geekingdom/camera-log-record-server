# 原设计对照与补齐记录

本表以“设备日志记录服务设计文档（任务配置与命令模板整合版）”及后续设备行为要求为基准。已有接口不能等同于控制台完整交付，短时合成测试不能等同于生产容量验收。

## 模块与用户流程

| 模块 | 已有基础 | 本轮补齐 | 后续验收边界 |
| --- | --- | --- | --- |
| 设备资源 | 任务独立创建 | 默认资源入口、海康 Digest/Basic ISAPI 认证、串口服务器、资源下创建和查询任务、连接 IP 与协议约束；同端口允许多任务 | 开发阶段统一重置为资源结构，不保留独立任务兼容分支；设备真实凭据由用户填写认证 |
| 设备日志目录 | 每任务隔离 | 同海康 IP、型号、短序列号生成稳定父目录，任务和运行作为子目录；全部使用统一路径 | 多节点为同一相对路径，不自动合并节点物理磁盘 |
| 控制台 | 任务、模板、节点简易列表；任务编辑抽屉 | 独立侧栏工作空间、概览、中文错误状态、任务诊断、响应式视觉体系 | 逐页桌面与移动端真实浏览器验收 |
| 任务配置 | 三协议、账号校验、有序初始化、定时项、模板副本、版本编辑、启停、SSH 暂停继续 | 点击任务进入独立日志工作台 | 模板分页操作和执行历史需持续核对 |
| 任务操作展示 | 原先每行固定显示启停按钮 | 按协议、实际状态、期望状态显示可用动作，串口采集中只显示停止，SSH 暂停后显示继续；过渡期隐藏重复控制 | 服务端仍负责最终权限与状态校验 |
| 实时打印 | 唯一连接接收、WebSocket 续传、字节去重、限速与有界虚拟列表、手动命令 | 一级日志工作台、任务搜索选择、视口实测高度、原始日志查看入口 | 缺口精确字节定位还需完善，不能把浏览器省略当作原始日志丢失 |
| 小时归档 | 校验后原子发布、清单摘要、小时下载和多选打包 | 上海日期筛选、小时分页、稳定聚合状态、片段身份/块序号/摘要、原文字节分段查看 | 归档摘要通过不代表设备断网期间无缺口 |
| 搜索下载 | 有界时间搜索、下载配额、取消、Range 和授权浏览器下载 | 按冻结片段真实推进进度，结果分页与进度条 | 单个大文件内部扫描进度粒度仍受片段边界限制 |
| 第三方接入 | Bearer Token、权限范围、创建撤销后端接口 | 服务账号列表、创建、一次性口令、权限及任务范围、撤销界面 | 管理员权限、过期与撤销实际校验 |
| 后台配置 | 环境变量、worker 自登记、7 天默认保留 | 版本化保留策略、节点登记和有效配置管理页面 | 配置必须影响维护和调度，不把登记伪装成已部署节点 |
| 审计与事件 | 操作审计和运行事件存储 | 独立审计/事件页面，时间和身份筛选、分页详情 | 敏感字段不得回显 |
| PSH/ASH | 原文密文提取、模拟解密、ls 探测、串口交错识别、Ctrl-C 后命令通道恢复 | 失败仅影响当次 debug；后续定时及重连初始化可再次执行，单次不重复提交口令；未确认退出密码提示时持续采集并保护普通命令 | 10003 尚未确认有效口令；实际解密服务不可达时不尝试触发设备锁定 |

## 分布式与容量差距

- 已修复暂停恢复的领取失败端点锁竞态，补偿与本次领取 token 关联，过期恢复领取可以重新获得；四个回归场景覆盖停止、并发后继领取和租约恢复。该局部修正不等同于完整分布式 fencing 验收。
- 运行代次目前未覆盖所有旧实例回写边界，需要继续核对 fencing、命令预算和端点锁释放条件。基础设施隔离仍是接管前置条件。
- 节点暂停、停止、释放和运行时状态/调试回写已增加任务、运行、节点、代次条件；旧归属不匹配时不清理后继锁与操作，本机容器按对象身份移除。已建连运行释放时在数据库收尾完成前保留节点归属，便于清理失败后的重试。监督器成功读取快照后主动关闭失属、阻塞或节点隔离的旧实例；异步释放和进程退出异常绑定原归属。重连复位及 CONNECTING 回调准入失败不再打开连接，已阻塞状态不能被旧回调覆盖。命令预算、多集合收尾的持久恢复与操作记录原子性仍需串联，不据此宣称分布式隔离完成。
- 会话结束时的命令收尾已限定任务、运行及会话 ID；未创建采集器时不执行命令清理。回归覆盖新会话、新运行、其他任务和已完成命令不被旧实例取消，此项不代表任务状态与端点锁的代次隔离已完成。
- 定时占用预算前核对回调的任务、运行、会话及数据库当前归属、采集状态和运行意图。定时待回写记录按会话与配置 ID 分隔，结果仅更新原会话仍为 SENDING 的记录，迟到回调不覆盖 UNKNOWN 或新会话执行；会话收尾清除其内存映射。该检查与预算递增、执行记录插入及设备写入仍非原子事务。
- 手动命令领取前核对当前运行归属与会话，发送使用数据库原子领取结果，迟到返回不覆盖已确定的收尾状态。配额只统计当前会话；节点每周期最多清理 100 条旧排队记录，再精确选择当前会话命令，旧队列不阻塞新交互。清理使用固定记录身份快照并复核归属，不取消期间新插入的后继会话记录。归属读取与预算/命令领取、设备发送尚非同一原子事务；并发入队的严格配额原子性仍待完善。
- 写入延迟已从采集器单调时钟测量连通至节点心跳、调度和本地建连复核。以最慢一路近 60 秒批次 P99 上界及未完成批次年龄控制新任务准入，超过 200 ms 时暂停准入但保留已有采集；这不是生产 P99 达标证明。多调度周期交接下的节点容量原子准入仍待加强。
- 时钟回拨会产生新片段并记录 `CLOCK_ROLLBACK` 运行事件（前后接收时间、会话、块序号、文件 ID 和中文说明），可在审计页面按类型查询。每路最多两个后台待压缩任务，连续回拨时实施背压；已用模拟时间及慢压缩验证顺序和队列上限，未修改真实服务器时钟。
- 500 路每路 1,200 行/秒持续 24 小时、8 个 Linux 节点和 P99 文件可读延迟不超过 200 ms，尚无同等范围的验收证据。五秒合成测试仅证明该样本的字节与时间戳校验。

所有新增模块以接口测试、前端构建、真实浏览器交互及受限联调结果为准，最终验证记录见 `validation.md`。本表不宣布原设计已全部完成。

## 节点登记兼容语义

`node_configs` 是管理员对已登记节点的容量、准入开关和预期地址配置，不是 worker
启动许可。为兼容已有通过环境变量部署、尚未登记的采集节点，未登记 worker 仍会上报
心跳并按本机环境容量参与新连接；登记后才会额外施加管理员配置和地址一致性检查。将
未登记节点改为默认拒绝准入需要单独迁移与部署编排，避免升级时中断现有采集。
