# 验证记录

本页仅记录已实际执行的验证和其边界，不能替代生产容量验收。

## 真实设备会话

已使用两台真实设备完成两轮 SSH pause/resume 验证。每轮 pause 后等待 12 秒；记录结果为 `release=0`、`resume=1`。恢复后保持同一 `runId`，同时创建新的 `sessionId`，符合暂停释放会话、恢复重新建连的预期。

## Collector 摘要一致性

最新本地合成验证为 500 路、总计 3,000,000 行：

| 指标 | 实测值 |
| --- | ---: |
| `sourceElapsed` | 5.000 s |
| `total` | 6.636 s |
| 输入原始字节 | 768,000,000 |
| 写入字节 | 834,000,000 |
| 压缩归档字节 | 11,276,872 |
| 主进程峰值 RSS | 246,022,144 B |
| 时间前缀校验 | `true` |

数据源为合成的重复日志行。极高压缩率来自重复内容，不能代表真实设备日志的压缩率；该记录验证前缀与摘要一致性以及本地资源观测，不构成设备吞吐、端到端吞吐、24 小时稳定性或生产容量结论。

## 自动化测试基线

此结果包含每秒同步和单独压缩进程，RSS 不含压缩子进程。复现命令为 `python scripts/benchmark_collector.py --routes 500 --seconds 5 --output .local/new-benchmark`。

本次记录时后端测试为 58 项通过，前端测试为 8 项通过。浏览器验收覆盖模板填充、任务表单、实际时间戳日志、本地视图暂停继续与清空、移动端和原生下载，控制台异常为 0。4 个真实 WebSocket 订阅合计接收 80 帧，协议错误、偏移错误及实时缺口均为 0。

尚未执行多台 Linux 节点上 500 路持续 24 小时的端到端验收，也未证明 P99 文件可读延迟不超过 200 ms。Docker Compose 配置解析通过；镜像构建此前受镜像仓库访问影响，未把本机直接启动结果当作容器验收。
